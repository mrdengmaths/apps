How to Play & Help

Objective: Drag the points on the graph to make the blue parabola match the equation shown.

Controls:

  • Purple Point (Vertex): Drag this point to move the entire parabola left, right, up, or down. This changes the turning point.
  • Cyan Point (Branch): Drag this point to change the parabola's shape. Move it away from the vertex to make it wider, or closer to make it narrower. Dragging it across the horizontal line through the vertex will flip the parabola upside down.

Maths Hints (y = a(x-h)² + k):

  • The vertex (turning point) is at the coordinate (h, k).
  • The value of 'a' controls the opening. If 'a' is positive, it opens upwards. If 'a' is negative, it opens downwards. A larger |a| makes the graph narrower.
  • The y-intercept is where the graph crosses the y-axis (where x=0).
  • The x-intercepts (or roots) are where the graph crosses the x-axis (where y=0).
