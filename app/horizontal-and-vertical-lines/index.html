How to Find the Equation

Horizontal Lines (Flat)

A horizontal line goes straight across. Every point on this line has the exact same y-coordinate.

The equation is always in the form: y = a

The value 'a' is the y-intercept, which is where the line crosses the vertical y-axis.

Vertical Lines (Up and Down)

A vertical line goes straight up and down. Every point on this line has the exact same x-coordinate.

The equation is always in the form: x = a

The value 'a' is the x-intercept, which is where the line crosses the horizontal x-axis.
