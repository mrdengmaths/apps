How to Play

Objective: Your goal is to make a pizza that matches the customer's fraction order!

1. Read the Order: Look at the fraction addition problem (e.g., 1/4 + 1/3).

2. Find a Common Denominator: To add fractions, they need the same bottom number (denominator). Use the "Total Slices" slider to divide the pizza. For 1/4 + 1/3, a good choice for total slices would be 12.

3. Select the Slices: Click on the pizza to select the correct number of slices. For 1/4 + 1/3, you'd need to figure out the total:
   • 1/4 is the same as 3/12.
   • 1/3 is the same as 4/12.
   • So, 3 + 4 = 7. You need to select 7 slices!

4. Check Your Order: When you're ready, hit the "Check Order" button. If you're right, you'll earn tips! If not, read the hint and try again.

Scoring: The faster you answer, the more tips you get! But be careful, you lose tips for every mistake.
