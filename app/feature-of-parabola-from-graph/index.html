How to Play & Feature Guide

Objective: Identify the 5 key features of the parabola shown on the graph and enter them into the input fields.

1. Turning Point: The point where the parabola changes direction. Enter it as (x,y).
2. Max/Min: If the parabola opens downwards (like a frown), it has a Maximum. If it opens upwards (like a smile), it has a Minimum.
3. Axis of Symmetry: The vertical dashed line that cuts the parabola in half. Enter it as x=value.
4. Y-intercept: The point where the graph crosses the vertical y-axis. Enter just the y-value.
5. X-intercept(s): The point(s) where the graph crosses the horizontal x-axis.
  • If there are two, enter them separated by a comma, e.g., -2, 5. Order doesn't matter.
  • If there is one, enter the single value.
  • If there are none, type none.

Click "Check Answer" or press Enter. If you're correct, a "Next Question" button will appear. Good luck!
