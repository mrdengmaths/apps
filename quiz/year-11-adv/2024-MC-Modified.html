1.
Determine the gradient of the line perpendicular to \(y = \frac{x}{2} - 3\).
Correct Answer: C
The given line has gradient \(m = \frac{1}{2}\). A perpendicular line has gradient equal to the negative reciprocal, so \(m_\perp = -2\).
2.
What is the value of \(\log_{31}(586)\), correct to three significant figures?
Correct Answer: B
Using change of base: \(\log_{31}(586)=\frac{\ln 586}{\ln 31}\approx1.8555\ldots\). To three significant figures this is \(1.86\).
3.
Given that \(\log_a 4 = 0.420\) and \(\log_a 5 = 0.488\), find \(\log_a 100\).
Correct Answer: C
Write \(100 = 4\times25\). Then \(\log_a100 = \log_a4 + 2\log_a5 = 0.420 + 2(0.488) = 1.396\).
4.
The graph of the gradient function, \(f'(x)\), is shown. For what value(s) of \(x\) does \(f(x)\) have stationary points?
Correct Answer: D
Stationary points of \(f(x)\) occur where \(f'(x)=0\), so we read the \(x\)-intercepts of the gradient graph. The curve crosses the \(x\)-axis at \(x=-3\), \(x=1\), and \(x=2\).
5.
Determine the set notation represented by the shaded area in the Venn diagram.
Correct Answer: C
All of set \(A\) (including the overlap) is unshaded, while everything outside \(A\) is shaded. That region is the complement of \(A\), i.e. \(A'\).
6.
Determine the value(s) of \(k\) for which \(|2k - 1| = k\).
Correct Answer: D
Since \(|2k-1|\ge0\), we need \(k\ge0\). Solve both cases: \(2k-1=k\Rightarrow k=1\), and \(-(2k-1)=k\Rightarrow 1=3k\Rightarrow k=\frac13\). Both satisfy the equation.
7.
Determine the value of \(p\) so that \(\frac{a^2a^{-3}}{\sqrt{a}} = a^p\).
Correct Answer: A
Combine powers in the numerator: \(a^2a^{-3}=a^{-1}\). Also, \(\sqrt{a}=a^{1/2}\). So \(\frac{a^{-1}}{a^{1/2}}=a^{-1-1/2}=a^{-3/2}\), hence \(p=-\frac{3}{2}\).
8.
The graph of a function \(y=f(x)\) is shown below. It has a horizontal asymptote at \(y=-2.5\). Which statement correctly describes its domain and range?
Correct Answer: A
The graph starts just to the right of \(x=2\) with an open circle at \((2,-3)\), so \(x=2\) is excluded and domain is \((2,\infty)\). The highest value is \(-1\) at the filled point \((3,-1)\), and the curve approaches \(y=-2.5\) from above without touching it, so range is \((-2.5,-1]\).
9.
What is the area, in \(cm^2\), of a sector with radius \(9\,cm\) and arc length \(18\pi\,cm\)?
Correct Answer: B
For a sector, \(A=\frac12 rL\), where \(L\) is arc length. So \(A=\frac12\times9\times18\pi=81\pi\,cm^2\).
10.
Given that \(f(x)=3x\) and \(g(x+1)=2x-4\), which expression is \(f(g(x))\)?
Correct Answer: A
Let \(u=x+1\), so \(g(u)=2(u-1)-4=2u-6\), hence \(g(x)=2x-6\). Then \(f(g(x))=3(2x-6)=6x-18\).
