1.
The solution of the inequality \(-3x + 4 < 2 - 5x\) is:
Correct Answer: A
Add 5x to both sides: 2x + 4 < 2. Subtract 4 from both sides: 2x < -2. Divide by 2: x < -1.
2.
What is the gradient of the line \(3y - 4x = 12\)?
Correct Answer: C
Rearrange into y = mx + c form: 3y = 4x + 12, then y = (4/3)x + 4. The gradient m is 4/3.
3.
Which of the following is equal to \(145^\circ 24'\) in radians, correct to three decimal places?
Correct Answer: B
First convert minutes to degrees: 24' = 24/60 = 0.4 degrees. So, 145.4 degrees. Convert to radians: 145.4 * (π / 180) ≈ 2.5377... which rounds to 2.538.
4.
What is the domain and range of the function \(g(x) = \frac{1}{\sqrt{x+2}}\)?
Correct Answer: A
For the square root to be real and non-zero (in denominator), x+2 > 0, so x > -2. Domain is (-2, ∞). Since numerator is positive and denominator is positive, g(x) is always positive but never reaches 0. Range is (0, ∞).
5.
A function is defined by the rule:

\( h(x) = \begin{cases} x^2 - 3, & x \le 2 \\ \frac{10}{x}, & x > 2 \end{cases} \)

What is the value of \(h(-2) \times h(5)\)?
Correct Answer: B
Since -2 ≤ 2, use the first rule: h(-2) = (-2)² - 3 = 4 - 3 = 1. Since 5 > 2, use the second rule: h(5) = 10 / 5 = 2. Therefore, h(-2) * h(5) = 1 * 2 = 2.
6.
Which of the following is a correct simplification of \( \log_a\left(\frac{a^4 \sqrt{y}}{y^3}\right) \)?
Correct Answer: A
Using log laws: log_a(a^4 * y^(1/2)) - log_a(y^3) = log_a(a^4) + log_a(y^(1/2)) - 3log_a(y) = 4 + 1/2*log_a(y) - 3log_a(y) = 4 - (5/2)log_a(y).
7.
Which of the following Venn diagrams represents \(A \cap \overline{B}\)?
Correct Answer: A
A ∩ B̄ (A intersect not B) represents the region that is inside A AND outside B. This is the part of circle A that does not overlap with circle B (often called "A only").
8.
The time, \(T\) hours, taken to travel between two cities varies inversely with the average speed, \(v\) km/h. When the average speed is \(60\) km/h, the journey takes \(4\) hours.

What average speed is required to complete the journey in \(3\) hours?
Correct Answer: C
Inverse variation model: \(T = \frac{k}{v}\). Substitute given values to find \(k\): \(4 = \frac{k}{60}\), so \(k = 240\). The formula is \(T = \frac{240}{v}\). To find the speed for a \(3\)-hour journey, substitute \(T = 3\): \(3 = \frac{240}{v}\), which gives \(v = \frac{240}{3} = 80\) km/h.
9.
Consider the function

\( f(x) = \begin{cases} (x-1)^2 + 1, & x < 0 \\ -2x + 2, & x \ge 0 \end{cases} \)

Which of the following statements about \(f(x)\) is correct?
Correct Answer: B
To check for continuity at \(x = 0\), evaluate both parts of the function at this boundary point. For \(x < 0\), the values approach \((0-1)^2 + 1 = 1 + 1 = 2\). For \(x \ge 0\), the exact value is \(-2(0) + 2 = 2\). Since both pieces converge to and equal \(2\) at \(x = 0\), the graph is unbroken and the function is continuous.
10.
The graph below shows part of the function \(y = f(x)\), which is an incomplete odd function.

Which statement about \(y = f(x)\) is true?
Correct Answer: C
Since \(f(x)\) is an odd function, it has rotational symmetry of 180° about the origin. The local maximum at \((3, 5)\) means there is a local minimum at \((-3, -5)\). The graph increases from the minimum at \(x = -3\) up to the maximum at \(x = 3\). Because the curve is rising as it passes through \(x = -2\), the gradient is positive there, meaning \(f'(-2) > 0\).
