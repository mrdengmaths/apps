2.
The quantity \(y\) is directly proportional to \(x^2\). When \(x = 3\), \(y = 18\). What is the value of \(y\) when \(x = 5\)?
Correct Answer: B
Since \(y = kx^2\), substitute \(18 = k(3)^2\), so \(k = 2\). Then \(y = 2(5)^2 = 50\).
3.
The solution of the inequality \(2(x-3) + 5 < 3x - 1\) is:
Correct Answer: C
Expand: 2x - 6 + 5 < 3x - 1, so 2x - 1 < 3x - 1. Add 1 to both sides: 2x < 3x. Subtract 2x: 0 < x. Hence x > 0.

5.
What is the domain and range of \(g(x) = \frac{1}{\sqrt{x-3}}\)?
Correct Answer: A
For the square root to be real, x-3 > 0, so x > 3. Since the denominator is positive and never zero, the output is always positive, so the range is \((0, \infty)\).
6.
Which of the following is a correct simplification of \(\log_a\left(\frac{y^5}{a^3\sqrt{y}}\right)\)?
Correct Answer: B
First rewrite as \(\log_a(y^5) - \log_a(a^3) - \log_a(y^{1/2}) = 5\log_a y - 3 - \frac{1}{2}\log_a y = \frac{9}{2}\log_a y - 3\).
7.
Which of the following is equal to \(210^\circ\) in radians, correct to three decimal places?
Correct Answer: B
Convert by multiplying by \(\pi/180\): \(210\times\pi/180 = 7\pi/6 \approx 3.665\) radians.
8.
Consider the function

\( f(x) = \begin{cases} (x+2)^2 - 1, & x < 0 \\ 3x + 1, & x \ge 0 \end{cases} \)

Which of the following statements about \(f(x)\) is correct?
Correct Answer: C
At x = 0, the left-hand limit is \((0+2)^2 - 1 = 3\), but the right-hand value is 3(0)+1=1. Because these are different, the function is discontinuous at x=0.
9.
What is the gradient of the line joining the points \((2, 5)\) and \((6, 13)\)?
Correct Answer: B
Gradient \(= \frac{13-5}{6-2} = \frac{8}{4} = 2\).
10.
A function is defined by the rule:

\( h(x) = \begin{cases} x^2 + 2, & x \le 1 \\ 4, & x > 1 \end{cases} \)

What is the value of \(h(1) \times h(3)\)?
Correct Answer: B
Since 1 ≤ 1, use the first rule: h(1)=1^2+2=3. Since 3 > 1, use the second rule: h(3)=4. Therefore h(1) × h(3)=3×4=12.
